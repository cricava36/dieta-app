# Dieta App React

Questa è una mini-app per gestire la dieta personalizzata giorno per giorno, vedere cosa mangiare, le ricette e la lista della spesa.

## Funzionalità
- Visualizza il menù giorno per giorno
- Visualizza ricette e ingredienti
- Lista della spesa automatica

## Avvio

1. `npm install`
2. `npm start`

---

Dati e struttura presi dal piano fornito.
